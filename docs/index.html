Vector Relay shows the AI chats that run on your own PC, and takes your next prompt to them.

  1. On the PC, type /phone in a chat.
  2. Scan the QR code it shows with this phone's camera.

The code holds a key that only your PC and this phone have. The relay in between passes sealed text it cannot read. Your phone needs the internet, not the same Wi-Fi as the PC.

Keep it as an app: tap Share, then Add to Home Screen. The icon takes your key along, so do not share this page's address.
